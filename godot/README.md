# Rust Mobile Range (Godot 4.7, Android)

Мобильный тир: ровная площадка, ящики/бочки-мишени, 3 оружия от первого лица с руками и родными анимациями из `.mdl`.

**APK:** `builds/RustMobileRange.apk` (debug-подпись, arm64-v8a + armeabi-v7a, Android 7.0+). Установка: скопировать на телефон и открыть (разрешить установку из неизвестных источников).

## Оружие
| Ячейка | Оружие | Модель | Анимации |
|---|---|---|---|
| 1 | Assault Rifle (AK) | `c_ak47u` | draw, fire1/2, fire_ads, reload |
| 2 | Python Revolver | `c_python` | draw, fire, fire_ads, dryfire, reload |
| рюкзак | Thompson | `c_thompson` | draw, fire, fire_ads, reload |

Руки — `c_arms_human`, приклеены к скелету оружия (bonemerge, как в GMod). Звуки перезарядки/доставания идут по событиям, зашитым в анимации `.mdl`.

## Управление
- Левая половина экрана — плавающий джойстик, правая — обзор свайпом.
- ОГОНЬ (большая справа + маленькая слева; с кнопки огня можно вести прицел), ПРИЦЕЛ, ПЕРЕЗАР., ОСМОТР, ПРЫЖОК.
- Снизу хотбар из 6 ячеек: тап — взять оружие. Кнопка рюкзака — инвентарь: тап по предмету, затем по ячейке — переложить (так Thompson переносится в хотбар). Патроны для перезарядки берутся из инвентаря.
- На ПК: стрелки, R, F, Space, Tab, 1–6.

## Сборка
Конвертация моделей: `tools/godot_conversion/` (Blender `bpy` 5.2 + SourceIO 5.5.4).
Экспорт: `godot --headless --path godot --export-debug Android ../builds/RustMobileRange.apk`.
