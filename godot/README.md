# Rust Mobile Range (Godot 4.7, Android)

Мобильный тир на ровной площадке: оружие и руки из Rust (GMod-аддоны этого репозитория) с родными анимациями из `.mdl`,
персонаж Rust с одеждой, 3-е лицо, боты-мишени и полный инвентарь как в gRust.

**APK:** `builds/RustMobileRange.apk` (debug-подпись, arm64-v8a, Android 7.0+). Установка: скопировать на телефон и открыть
(разрешить установку из неизвестных источников).

## Оружие (12)
| Тип | Предметы |
|---|---|
| Винтовки (5.56) | Assault Rifle (AK), LR-300, M249, SAR |
| ПП / пистолеты (пистолетные) | MP5A4, Thompson, Custom SMG, M92, Python, Revolver |
| Ближний бой | Rock (камень), Combat Knife (нож) |

Вьюмодели `c_*` + руки `c_arms_human` (bonemerge как в GMod, перчатки включаются по надетой одежде).
Анимации draw / fire / fire_ads / reload / dryfire / slash взяты из `.mdl`, звуки — по событиям внутри анимаций.
После перезарядки руки возвращаются в позу покоя (раньше у Python «пропадал» барабан).
Отдельных анимаций осмотра в моделях нет — осмотр сделан поворотом оружия в кистях поверх анимации (`InspectModifier`).

## Персонаж, одежда, 3-е лицо
Модель `characters/models/rust_model` + 12 вещей из `characters/clothing` (куртки, броня heavy plate, roadsign,
штаны, ботинки, перчатки, кепка, маска, бандана). Анимаций тела в репозитории нет (в GMod они берутся из стандартного
`m_anm.mdl`), поэтому стойка с оружием, ходьба, прицеливание по вертикали и удар сделаны процедурно (IK рук).
Модели оружия в мире `w_*` крепятся к руке так же, как в GMod (через кость `R_Hand`).

## Боты
Два бота в разной броне стоят на месте и смотрят на игрока. Хитбоксы на костях: голова (×2), грудь, живот, руки, ноги.
Урон уменьшается бронёй на соответствующей зоне. Звуки: хедшот (`sounds/combat/headshot.wav`), хитмаркер, попадание
по плоти, стоны, крик при смерти. Над ботом — имя и полоска HP, всплывающие цифры урона. После смерти падают и через
4 секунды встают.

## Инвентарь (как в gRust)
Слева — персонаж (крутится пальцем) с защитой по типам и 7 ячеек одежды; по центру — описание предмета, рюкзак 6×4 и
пояс 6 ячеек. Перетаскивание пальцем, или тап по предмету → тап по ячейке; двойной тап по одежде — надеть/снять,
перетащить одежду на персонажа — надеть.

## Управление
- Левая половина экрана — плавающий джойстик, правая — обзор свайпом.
- ОГОНЬ (большая справа + маленькая слева; с кнопки огня можно вести прицел), ПРИЦЕЛ, ПЕРЕЗАР., ОСМОТР, ПРЫЖОК, 3 ЛИЦО.
- Снизу пояс из 6 ячеек: тап — взять предмет в руки. Кнопка рюкзака — инвентарь.
- На ПК: стрелки, R, F, V (3-е лицо), Space, Tab, 1–6.

## Сборка
Конвертация моделей: `tools/godot_conversion/` (Blender `bpy` 5.2 + SourceIO 5.5.4):
`convert2.py` — вьюмодели с руками, `static2.py` — модели в мире, `player_conv.py` — персонаж и одежда,
`events2.py` — таблица анимаций и звуков `weapons.json`.
Экспорт: `godot --headless --path godot --export-debug Android ../builds/RustMobileRange.apk`.
